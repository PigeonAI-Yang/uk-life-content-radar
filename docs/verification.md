# 验证说明

## 环境前提

- Windows（微软桌面系统）。
- PowerShell 7，命令为 `pwsh`。
- 当前检查只读取项目文件，不安装依赖、不修改业务数据。

## 当前总门禁

来源：本项目 harness（验证脚手架）提供。

```powershell
pwsh -NoProfile -File scripts/check.ps1
```

该命令检查：

- harness（验证脚手架）必需文件存在。
- `SKILL.md` 保留必要元数据。
- PRD（产品需求文档）保留产品定义、非目标、接口契约和完成定义。
- SPEC（技术规格）保留统一运行边界与 MCP（模型上下文协议）对等规则。
- UI（用户界面）视觉规范保留空间规则与视觉验收。
- PLAN（实施计划）保留最小发布闭环与安装应用交付。
- TASK（任务）台账保留完整编号、最终依赖闭包和只验收不补功能的最终任务。
- TypeScript（类型化脚本语言）类型检查、ESLint（代码检查工具）、Vitest（单元测试工具）和 Forge（打包工具）构建。
- 每个 TASK（任务）只在总门禁后运行自己的 `test:task-NNN` 定向验收，避免重复执行已完成任务。
- TASK-019（任务 019）通过 TASK-000 至 TASK-018 的任务回执汇总最终完整链，不在日常总门禁重复跑全历史。

`npm run typecheck`

## 代码检查

`npm run lint`
