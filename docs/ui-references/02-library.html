英国租客权利改革：房东不得无理由驱逐

GOV.UK2026-07-24中文摘要

英国租房制度正在发生重要变化。新的改革将取消房东在没有给出法定理由时终止租约的做法，并对租金上涨、房屋维修和租客申诉建立更清晰的规则。

已摘录
房东需要使用明确的法定理由终止租约，并向租客提供对应证据。租客仍需按合同支付租金并遵守合理义务。

对在英中国人来说，最重要的不是记住法案名称，而是知道收到通知后应检查什么、保留哪些文件，以及去哪里核验和申诉。

当前资料已经过官方来源核验。专业解释和个人案例仍需与具体事实分开使用。
