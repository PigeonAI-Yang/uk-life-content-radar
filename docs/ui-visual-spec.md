## 2. 设计原则

1. 人类阅读、查找、写作和引用是主任务；对象标识、快照、索引和智能体日志退居详情。
2. 一级导航固定：工作台、浏览与收集、资料库、内容、素材库、发布包、账号、任务、设置。
3. 主题、地区、平台、状态、归档和保存视图仅在模块内部出现。
4. 额外宽度必须服务阅读、引用、素材或预览；不得产生无业务用途的巨大空白列。
5. 正文永远是编辑页的视觉主区；资料、素材、引用、待核验与平台预览共用一个可切换的右侧槽位。
6. 使用 Windows（微软桌面系统）浅色中性底、克制灰阶选中态、单一主动作蓝和细分隔线；不做营销式卡片墙。
7. 品牌蓝只用于当前页面最重要的主动作、链接、进度和必要状态，不用于侧栏或列表选中项的装饰边线。

## 3. 窗口与网格

- 最小验收窗口：1280 × 720 个 CSS（层叠样式表）像素。
- 主设计基准：1600 × 900 个 CSS（层叠样式表）像素。
- 额外验收：1920 × 1080、2560 × 1440。
- 顶栏：48 像素。
- 展开侧栏：176 像素；收起：56 像素。
- 页面内边距：12 至 18 像素。
- 控件高度：32 至 36 像素；主按钮：36 至 40 像素。
- 底部系统状态条若存在，不高于 24 像素，不承载业务操作。

### 3.1 响应布局

| 可用宽度 | 资料库 |
| --- | --- |
| 小于 1180 | 全宽列表；阅读器为全高抽屉 |
| 1180 至 1499 | 全宽列表；阅读器以 420 至 560 像素覆盖或推开 |
| 1500 及以上 | 常驻双栏；列表占 48% 至 58%，阅读区占 42% 至 52% |

打开或关闭阅读器不得丢失列表选择、滚动位置、筛选和排序。任何宽度超过 120 像素且无内容、无交互用途的纵向空区均为验收失败。

## 4. 颜色

| 用途 | 色值 |
| --- | --- |
| 品牌与主动作 | `#0F6CBD` |
| 主动作悬停 | `#115EA3` |
| 页面背景 | `#F7F8FA` |
| 业务面板 | `#FFFFFF` |
| 主文字 | `#242424` |
| 次文字 | `#616161` |
| 弱文字 | `#8A8886` |
| 边框 | `#E1E4E8` |
| 选中背景 | `#E9E9E9` |
| 成功与已核验 | `#107C41` |
| 待处理 | `#B75C00` |
| 失败与危险 | `#C50F1F` |

颜色不是唯一状态载体，必须同时显示文字或图标。普通业务区不加阴影；抽屉、菜单和对话框可使用轻阴影。侧栏、列表、大纲和普通页签的选中态使用灰色背景或字重变化，不使用蓝色左边线、蓝色描边或大面积浅蓝底。

## 5. 字体与层级

字体顺序：Segoe UI（微软界面字体）、Microsoft YaHei UI（微软雅黑界面字体）、系统无衬线字体。

| 内容 | 字号与行高 |
| --- | --- |
| 页面标题 | 24 至 28 像素，1.25 |
| 区块标题 | 16 至 18 像素，1.4 |
| 正文阅读 | 14 至 16 像素，1.6 至 1.8 |
| 导航 | 14 至 15 像素，1.4 |
| 表格标题 | 13 至 14 像素，1.4 |
| 摘要与辅助信息 | 12 至 13 像素，1.5 |

关键业务信息不得使用 11 像素文字。标题单行省略，摘要最多两行。

## 6. 形状与交互

- 圆角：6 至 8 像素。
- 边框：1 像素。
- 点击目标至少 32 × 32 像素，关键动作建议 40 × 40 像素。
- 每页仅一个最显著主动作。
- 选中、悬停、键盘焦点和禁用必须可区分。
- 普通选中态由浅灰背景和字重表达；键盘焦点环仍使用品牌蓝，不得为了视觉简约而移除。
- 浮层打开时控制焦点；关闭后焦点回到触发点。

## 7. 页面规范

### 7.1 工作台

- 最多四个高频摘要区和一个紧凑任务表。
- 首屏必须看见继续创作、待处理收件、待审核和失败项。
- 不展示虚荣统计、大图表、营销式大卡或装饰留白。

### 7.2 浏览与收集

- 顶部是标签栏、地址栏、返回、前进、刷新和网页内查找；浏览内容占据剩余主区。
- 收集入口固定为收藏网页、摘录选中内容、保存图片和接管下载文件。
- 收集面板显示资料库、素材库或内容项目落点；完成后显示对象名称和可打开回执。
- 登录失效、下载失败、页面不可读取和疑似重复不得用同一种笼统错误表示。
- 窄宽度下收集面板覆盖浏览区，关闭后恢复原标签、页面滚动和选区。

### 7.3 资料库

- 资料行普通高度 60 至 72 像素；高密度模式 48 至 56 像素。
- 双栏时正文列吃掉剩余宽度；来源 140 至 180 像素，时间 96 至 120 像素，状态 72 至 96 像素。
- 主题、标签与使用次数进入标题下摘要行，不单独占宽列。
- 单击选中并预览；双击或回车进入沉浸阅读。
- 阅读器首屏显示标题、来源、时间、核验状态和正文。查看原文、摘录、加入内容是固定主动作。
- 来源上下文和“用于哪些内容”按需展开；滚动列表不重置阅读器。

### 7.4 内容编辑

- 大纲宽 200 至 260 像素，可折叠。
- 正文是唯一主区，可编辑宽度不得小于 600 像素。
- 右侧资源槽宽 320 至 420 像素，可在资料、素材、引用、待核验和平台预览之间切换。
- 底部引用区默认折叠，且与右侧引用视图互斥。
- 公共草稿与三个平台版本使用页签。重新生成不得静默覆盖人工修改。
- 引用可回看原文片段与上下文；删除引用不删除资料。

### 7.5 素材库

- 支持网格与列表切换。
- 缩略图显示尺寸、来源、使用次数和版本；真实路径仅在详情显示。
- 图片处理进入专用编辑视图，保存为新版本，原图不可覆盖。

### 7.6 发布包与任务

- 发布包以平台、版本、批准状态和真实产物为中心，不以内部指纹为主视觉。
- 任务列表只显示名称、触发者、进度、结果、可理解错误和取消；技术日志按需进入详情。
- 部分成功必须逐项标明成功与失败，不显示整体成功。

### 7.7 账号

- 主区采用账号列表与详情编辑双栏，不使用账号大卡墙。
- 详情按名称与定位、受众与语气、禁用表达、平台身份、默认模板分组。
- 页面明确显示该账号的内容和发布包数量；资料与素材只显示使用关系，不表现为账号私有副本。
- 未配置平台身份、模板失效和存在未保存修改必须有独立状态。

### 7.8 设置

- 首屏显示业务根目录、数据库与临时目录、文件数量、容量、相对上次扫描的增长和最近扫描时间。
- 根目录已有数据后只读显示，不提供普通切换按钮。
- 平台尺寸模板、默认导出目录和语义索引状态采用紧凑分区。
- 磁盘不可读、空间不足、外部文件丢失和统计失败必须显示影响范围与重新扫描入口。

## 8. 统一组件

第一版统一使用：全局搜索、模块页签、筛选条、保存视图、数据表、素材网格、详情阅读器、编辑器、大纲、右侧资源槽、版本切换、平台预览、审批条、任务行、通知条、加载骨架、空状态、错误状态、确认对话框和短暂回执。

主要页面均须覆盖：

- 首次空状态；
- 大量数据；
- 搜索无结果；
- 加载中与加载失败；
- 离线但本地可用；
- 归档对象；
- 只读历史版本；
- 未保存修改；
- 外部文件丢失；
- 任务部分成功；
- 批准失效；
- 磁盘空间不足。

### 8.1 页面状态验收矩阵

| 页面 | 必须覆盖的非理想状态 |
| --- | --- |
| 工作台 | 首次空、加载失败、任务部分成功、失败任务 |
| 浏览与收集 | 离线、登录失效、页面不可读、下载失败、疑似重复 |
| 资料库 | 搜索无结果、归档、加载失败、外部来源不可用 |
| 内容 | 未保存修改、只读历史版本、批准失效、版本冲突 |
| 素材库 | 外部文件丢失、外部修改、处理失败、磁盘不足 |
| 发布包 | 未批准、批准失效、部分成功、文件缺失 |
| 账号 | 首次空、平台身份缺失、模板失效、未保存修改 |
| 任务 | 已取消、已中断、失败、部分成功 |
| 设置 | 根目录不可读、统计失败、磁盘不足、索引不可用 |

## 9. 可访问性

- 所有业务操作可用键盘到达，逻辑顺序与视觉顺序一致。
- 焦点环清晰；图标有可读名称；表头、排序、页签、复选框和状态可被辅助技术识别。
- 普通文字对比度至少 4.5:1，大字至少 3:1。
- 支持 Windows（微软桌面系统）125% 与 150% 缩放。
- 文本放大到 200% 时，批准、保存、返回和关闭面板仍可见可达。
- 不依赖悬停才显示必要能力。

## 10. 禁止项

- 把签证、租房等主题放入一级侧栏。
- 用数百像素的弹性空白填充超宽屏。
- 给侧栏按钮、列表行或大纲选中项添加蓝色竖边、蓝色描边或装饰性蓝色边角。
- 把快照、哈希、索引、命令证据或智能体日志作为主界面中心。
- 新增聊天框、提示词区或对话历史。
- 用卡片流管理十万级资料。
- 编辑器同时常驻大纲、资料、素材、引用和平台预览五栏。
- 把归档或存储中心提升为一级导航。
- 在每一行展示真实文件路径。

## 11. 视觉验收

1. 在 1280、1600、1920、2560 四档宽度生成全页面截图，无无意义大空区、横向溢出或关键操作遮挡。
2. 1600 宽资料页同时看到列表和阅读区；列表保留标题、摘要、来源、时间和状态。
3. 1280 宽打开、关闭阅读器后，选中项与滚动位置不丢。
4. 1600 宽内容页正文可编辑宽度至少 600 像素；切换右侧资源不改变正文和滚动位置。
5. 仅用键盘完成：全局搜索 → 筛选资料 → 选中 → 摘录 → 加入内容 → 编辑 → 插入引用 → 保存版本。
6. 在系统 150% 缩放及文本 200% 放大下重复批准和保存关键链。
